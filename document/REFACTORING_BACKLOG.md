# 重构追加任务清单

本清单只收录执行主计划时发现、但不应打断当前编号的工作。任务按目标阶段统一处理；除非成为数据安全或生产阻断问题，不在发现时继续向下拆分。

| ID | 目标阶段 | 优先级 | 问题 | 完成标准 |
| --- | --- | --- | --- | --- |
| B15-01 | R15 | P1 | 审核拒绝或举报下架目前只依赖发布状态，作者再次编辑可重置状态；需要独立、持久化的审核限制语义。 | 增加明确的限制状态与原因、生产数据迁移和预检；作者编辑不得绕过下架，管理员解除限制有审计记录。 |
| B15-02 | R15 | P1 | 详情预览 URL 直接拼接战术板代码；分享图可能在剧透或不适内容揭示前生成，并且长标题可能溢出画布。 | 预览参数安全编码；内容警告状态贯穿预览和分享图；标题按画布宽度截断或换行并有回归测试。 |
| B15-03 | R15 | P2 | 复制逻辑和计数更新分散；剪贴板失败提示会把完整战术板代码写进全局通知。 | 统一复制反馈和计数入口；失败时提供可访问的手动复制方式，不在通知中回显完整代码。 |
| B15-04 | R15 | P2 | 点赞和收藏采用“先查询再切换”，并发请求可能得到与用户意图相反的结果。 | 改为显式目标状态或事务化操作；并发与重复请求测试证明最终状态稳定。 |
| B16-01 | R16 | P1 | Django Admin 的分享批量公开/私有操作仍更新已删除的 `is_public` 字段。 | 改用 `visibility` 与审核策略，补管理员动作测试和清晰反馈。 |
| B17-01 | R17 | P2 | 详情页的审核日志、作者合集和相关合集总数没有边界；相关合集窗口查询仍需扫描候选条目。 | 分页或设置有解释的上限；建立查询数量、返回规模和大数据量耗时基线。 |
