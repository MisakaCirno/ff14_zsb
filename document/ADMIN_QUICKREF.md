# 🎛️ Django 管理后台 - 快速参考

## 访问信息
- **地址**: http://127.0.0.1:8000/admin/
- **凭据**: 项目不提供默认管理员用户名或密码
- **首次创建**: `python manage.py createsuperuser`，按提示交互输入

## 主要功能

### ✅ 已启用的管理模块
1. **战术板分享管理**
   - 查看/编辑/删除所有分享
   - 批量设为公开/私有（公开操作仅处理已审核通过且无限制的分享）
   - 按作者、时间、状态筛选
   - 搜索标题、ID、描述

2. **用户管理**
   - 查看所有用户和昵称
   - 内联编辑用户资料
   - 权限和组管理
   - 用户激活/停用

3. **用户资料管理**
   - 编辑昵称和简介
   - 查看分享统计
   - 按时间筛选

## 增强特性

### 🌟 界面优化
- ✅ 完全中文化界面
- ✅ 自定义标题和欢迎信息
- ✅ 显示昵称而非用户名
- ✅ 分享数量统计

### 🔍 搜索增强
- 支持搜索作者昵称
- 多字段组合搜索
- 实时筛选结果

### 📊 数据展示
- 列表分页（每页20条）
- 日期层级浏览
- 字段排序
- 过滤器快速筛选

### ⚡ 批量操作
- 批量公开不会代替审核或解除内容限制；不符合条件的分享会跳过并给出计数
- 批量私有只收紧可见性，不改写审核状态或限制证据
- 批量删除（需确认）
- 自定义批量操作

## 快速操作

### 修改管理员密码
```bash
python manage.py changepassword <管理员用户名>
```

也可以使用管理后台右上角的“修改密码”。新密码只在交互提示中输入。

### 创建新管理员
```bash
python manage.py createsuperuser
```

### 查看操作日志
```
管理首页 → 最近操作
```

## 安全建议
⚠️ 不要在代码、文档、脚本、工单或版本库中保存管理员密码。发现凭据可能泄露时，立即使用 `changepassword` 交互轮换并验证旧密码已失效。
